# Contributing

1. Install the pinned Node version, dependencies and model using the README.
2. Keep changes focused. CLI and MCP should continue to use the same core.
3. Run `npm test`; add a focused regression for behavior changes.
4. Include the problem, resulting behavior and validation in the pull request.

Use synthetic records and temporary databases. Never submit personal memory databases, credentials, model weights or complete chat transcripts. Generated test reports belong in `test-results/` and are ignored by Git.
